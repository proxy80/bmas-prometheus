BMAS Project Prometheus — Ports, NFS/S3 Streaming & MoE Guide

  • Custom Controller & Engine Ports (Doesn't have to be :5000 or :8000): Launch on any custom ports via CLI flags, or change the Engine Port live in the top-left panel:
./launch_prometheus.sh --port 7070 --engine-port 9000
  • Streaming from NFS, S3 Cloud, or HuggingFace API directly into /dev/shm:
    • NFS / Lustre / BeeGFS: Select NFS Mount and scan your mounted share (e.g., /mnt/nfs/models).
    • AWS S3 / MinIO: Select AWS S3 / MinIO, enter s3://your-bucket/qwen36_i4_gs64, and click Stream to RAM (streams via s5cmd or aws s3 sync directly into /dev/shm/colibri_models/).
    • HTTP / HuggingFace API: Select HTTP / HuggingFace API, enter repo ID or URL, and click Stream to RAM.
