MoE Model Installation & Colibrì Quantization Guide

Why did olmoe_i8 (2.2G) and qwen36_i4_gs64 (18G) work while Qwen3.8-27B (16G) and Qwen3.6-35B-Archive (64G) failed?

  • Colibrì Native Models (COLIBRI READY): Folders like olmoe_i8 and qwen36_i4_gs64 have been quantized via convert_weights.py into INT8 or INT4 GroupSize-64 shards.
  • Raw HuggingFace Checkpoints (NEEDS QUANT CONVERT): Qwen3.6-35B-Archive (64G) is raw unquantized BF16 safetensors. Convert it into a 18GB INT4 Colibrì directory first:
python3 /mnt/ssd/convert_weights.py \ --input /mnt/ssd/models/Qwen3.6-35B-Archive \ --output /mnt/ssd/models/qwen36_i4_gs64 \ --quant int4_gs64
  • Expanding /dev/shm for 18GB–22GB Models: Ubuntu defaults /dev/shm to 50% of RAM (15.6GB on a 32GB node). To stage an 18GB model into /dev/shm without error, expand tmpfs to 24GB:
sudo mount -o remount,size=24G /dev/shm
